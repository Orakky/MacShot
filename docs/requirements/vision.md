# 产品愿景与定位

> 真源：愿景、目标用户、成功判据、反定位。范围与 ID 规则服从 `docs/charter.md`。

## 1. 一句话
把"看到屏幕上的东西 → 圈出来 → 说清重点 → 立刻用得上"这条路缩到一次按键和几次点击之内。

## 2. 目标用户
开发者、设计、需要频繁"拿图说话"的人。首版用户 = 你自己（macOS 15.7.4 / arm64 / 双屏环境的假设需在 M-1 实测确认，不预设）。

## 3. 三个高频场景（写成"此刻在做什么 → 要什么结果 → 今天靠什么凑合"）

| # | 场景 | 要的结果 | 现在的凑合办法 | MacShot 的差别 |
|---|---|---|---|---|
| S1 | 给别人指一个 bug 的位置 | 一张**恰好包含上下文**的图 + 红箭头，直接粘进聊天 | 系统截图 → 打开预览 → 裁剪 → 再复制，或整屏发出去让人自己找 | `F1` → 拖框 → 画箭头 → `⌘C`，焦点回原 app（FR-EXP-001、FR-SESS-003）；若只是想先钉住看，按 `Enter` 直接置顶（FR-PIN-018） |
| S2 | 照着设计稿/别人给的图改自己的界面 | 图**一直浮在上面**，能缩放能半透明，边看边改 | 把图拖到另一个显示器、或反复 ⌘Tab 切换 | `F3` 把剪贴板图钉住 + 滚轮缩放 + `⌘`滚轮透明（FR-PIN-006/003/017） |
| S3 | 截图后发现圈错/漏写一个字 | 在原图上改，不必重截 | 重截一次（且此时画面已经变了，常常截不到） | 贴图内 `E` 再编辑（FR-PIN-005，D-04） |

S3 正是 D-04 的存在理由；也是最贵的一条（`ADR-005` 后果、NFR-005 代价）。若你在 Q-12 改选 B，S3 就退出首版，本文的场景表随之少一行——这种连带关系是"改一处要扫全文档"的原因（`docs/charter.md` §5 单一真源规则）。

## 4. 成功判据（发布后自评指标，非承诺；全部要可观察）

| ID | 指标 | 观察方法 | 达标线（我的建议，**待你裁决**） |
|---|---|---|---|
| G-01 | 首版真的被日常使用 | 一周内 `t.hotkey→frozen` 日志行数（不记内容，只记次数） | ≥ 20 次/天且连续 5 天 |
| G-02 | 没有被"嫌麻烦"绕过 | 是否还出现"用系统截图 + 预览裁剪"的操作 | 你自己确认：一周内 0 次 |
| G-03 | 贴图确实承担对照用途 | 会话统计：`commit(.pin)` 占比 | ≥ 20% |
| G-04 | 再编辑值得它的代价 | `E` 进编辑态次数 / 贴图次数 | ≥ 15%（低于此值说明 NFR-005 的代价换来的收益薄，回 Q-12 重议） |
| G-05 | 无"我以为截成功了"事故 | `failed`/`gate` 状态的会话占比与后续人工报错 | 0 次静默黑图（`ADR-008` 红线） |

实现要求：G-01/G-03/G-04 需要的计数只能通过**本地日志**得到，不联网、不遥测（NFR-030/032）。计数脚本 `scripts/usage-report.sh` 属 M-6 交付物。

## 5. 反定位（明确不是什么）

- 不是截图管理/相册（不做库、不做搜索、不做标签；历史是 P1 且上限极小，Q-06）。
- 不是标注设计工具（不做图层、蒙版、自由变换、对齐参考线的"设计软件化"）。
- 不做录屏/GIF、不做滚动截图、不做云同步与账号、不做更新弹窗与增值付费。
- 不追求"覆盖 Snipaste 全部功能"：差距表的存在是有意为之（`docs/reference/snipaste-gap.md` §8）。

## 6. 首版成功的最低定义
M-5 出口（`docs/plan/roadmap.md`）+ 上面 G-01/G-02 在**你自己**机器上成立。不是"功能齐"，而是"取代了你现在的凑合办法"。

## 7. 一年的方向（不承诺，只登记，防止每次重议）
`P1`：窗口/元素自动识别、重复区域、放大镜取色、贴图分组与穿透、`.macshot` 落盘再编辑、拖出、历史。
`P2`：图像效果（圆角/阴影/边框/水印）、OCR、跨屏选区、WebP/JPEG、多语言第三档。
明确不做：见 §5。

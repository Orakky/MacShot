# 已知限制（发布说明的取材地）

> 本文是**引用**：每条限制都指向它自己的真源 ID，不在此处新增决定。
> 用途：`M-6` 准出④"已知限制清单"与 README 使用章节的骨架。**写进发布说明的每一句都得在这里有出处**，
> 反过来也一样——台账里已知的口子不许在发布说明里被说成"支持"。

## 1. 功能边界（有意不做，本期）

| 限制 | 出处 | 用户会怎么撞上 |
|---|---|---|
| 贴图**分组**与**鼠标穿透**没有 | `charter.md` §6b Q-08（本期移到下一期）；`FR-PIN-011/012` 已降 P2 | 贴了很多张想归类、或想让贴图不挡点击 |
| **跨屏选区**不支持，选区不能同时跨两台显示器 | Q-09；`requirements.md` §5 | 双屏拉一个横跨两屏的框 |
| **滚动截图 / 区域录制 / 实时录制**没有 | Q-10、`requirements.md` §5 明确不做 | 想截长网页 |
| 界面**只有中文**，不跟随系统语言 | `ADR-016` | 非中文环境看不到英文界面 |
| 键盘**不能**完成全流程：选区必须鼠标拖出 | `nfr.md` §9.2（用户接受）；`FR-CAP-013` 留 P1 | 只用键盘的用户 |
| 放大镜里 **`W/A/S/D` 逐像素移动**没有 | `FR-CAP-016`（11-17 移出 P0） | 想像素级挪取样点 |
| 未保存的标注/贴图**退出即抛弃**，不提示 | Q-06；`charter.md` §6b | 关软件前忘了导出 |

## 2. 形态取舍（不是 bug，是代价）

| 现象 | 为什么 | 出处 |
|---|---|---|
| 极小贴图（如 `60×40`）编辑态**没有工具带**，只能按字母选工具 | 工具带预算 `min(160pt, 图片高)` 都不够，硬撑会让带比图还高 | `B-028` 定稿、`UI-004`、`E-061` |
| 贴图编辑态会**把窗口向下撑高**一条工具带 | 折行实测要盖掉 75% 画面；撑高保画面与导出不变 | `E-061`、`V-049` |
| 剪贴板 `types` 里除了 `public.png` 还有 `public.tiff` | 我们只交一个 PNG，**TIFF 是 AppKit 自己派生的**（对照组证明） | `ADR-014` 实测补充、`E-062` |
| **模糊工具拖拽期只画虚线轮廓**，松手才真糊 | 逐帧对整块区域跑 CPU 盒式模糊就是卡顿源；形状反馈给足，代价留一次（`V-053③` 钉着"不许逐帧真糊"） | `E-081` |
| **放大镜默认不自动弹**（11-18 改判 Q-07 的呈现档） | 用户不要截图时那个额外画面。要自动弹：设置「拖拽时显示放大镜」=开；任何时候 `⌥` 都能强制呼出 | `FR-CAP-016`、`UI-008` |
| **遮罩不再有"全局监听 Esc"那道保险**（11-19 权限收缩） | 那条要输入监控/辅助功能权限，而且没给权限时本来就不响——不能算逃生阀。真出路仍是五条：本地 keyMonitor 的 `Esc`、responder 链的 `Esc`、左上角 ✕、右键取消、再按一次截图热键。代价：遮罩拿不到 key 且你只用键盘时，`Esc` 可能不响应 | `NFR-037`、`V-063①`、`E-093` |
| 放大镜中心格的显示色与取样色有约 4% 偏差 | 色彩管理往返（sRGB→显示器→deviceRGB）；复制出去的串是**精确**的 | `E-068`、`V-051` |
| 关掉全部贴图后 RSS 会略低于基线 | 注册表空时压一次分配器（`malloc_zone_pressure_relief`），把缓存还给系统 | `E-072`、`NFR-008` |

## 4. D-04（贴图携带可编辑标注层）与 Snipaste 的真实关系

必须写清的事实：
1. Snipaste **免费版官方明示**"二次编辑将来才支持，现在只能靠撤销/重做找回图案"（S1）。
2. 二次编辑（Re-edit）与"从贴图右键切换标注显隐"是 **PRO** 功能（S3、S6 v2.8）。
3. "保存/复制时把标注烘焙成位图"这句，**未找到官方出处** → 不能当依据引用。
4. PRO v2.3.2 新增"复制/保存未缩放的原图"（S6）→ 可**推断**贴图的缩放只是显示态、源图保留，但同样不能当无损渲染的依据。

结论：**D-04 不是"抄 Snipaste"，而是把 Snipaste 的付费能力放进我们的首版必做项**。这条已写进 `docs/charter.md` §1.1 的代价清单（schema 冻结 + 两套宿主 + NFR-005 回退判据）。裁决时请把它当作"知情确认"而不是"对齐主流"。

## 5. 导出与剪贴板

| 点 | Snipaste | 出处 | MacShot |
|---|---|---|---|
| 保存格式含 JPEG 质量调优、WebP | S6 v2.7 / v2.8.6 | 官方 | P0 只 PNG；JPEG/WebP P1/P2 |
| 质量参数 `-1~100` | S4 | 官方 | 设置项 `export.quality` P1 |
| 剪贴板图像质量**不可调** | S4 | 官方 | 我们同结论：剪贴板走无损 PNG |
| 命名模板变量（含 `%title%` 等） | S6 v2.5.5 / v2.8.5 | 官方 | FR-EXP-003 的模板变量表参考 |
| Mac 版曾专门修"剪贴板/文件的 DPI 与色彩配置"问题 | S6 v2.2 Beta for Mac、v2.6.6、v2.10.6 | 官方 | **给 FR-EXP-004 提供依据**：这是真实踩坑点，必须实测 |
| 剪贴板同时写 PNG + TIFF 多表示 | — | **未找到出处** | Q-04 不能以 Snipaste 为理由，只能以"目标应用兼容性实测"为理由 |

## 6. macOS 权限（官方故障排查）

| 症状 | 需要 | 出处 |
|---|---|---|
| 截图全黑/无内容 | 屏幕录制权限（macOS 10.15 起） | S5，官方 |
| 元素检测、`W/A/S/D` 像素光标不工作 | **辅助功能权限** | S5，官方 |
| Web UI 元素检测在 Mac 默认关闭 | 开启后仍需授权 | S5，官方 |
| 热键冲突/失效 | 官方有专门修复记录（v2.4 Beta for Mac） | S6，官方 |

对我们：`FR-CAP-006`（屏幕录制引导）是 P0；**窗口/元素自动识别（FR-CAP-011）一旦开工就要面对辅助功能权限**，这条限制要写进 ADR-017 再决策，不要到 M-4 才发现。

## 7. Apple API 事实（已核实）

| API | 状态 | 出处 |
|---|---|---|
| `SCStream` | macOS 12.3+ | A1 官方 |
| `SCScreenshotManager.captureImage` | **macOS 14.0+** | A2 官方 |
| `CGWindowListCreateImage` | 弃用（页面标 deprecated，编译器文本 "first deprecated in macOS 14.0"，版本号由第三方 issue 佐证） | A3 官方 + 第三方 |
| `CGDisplayCreateImage` | 页面标 `deprecated: true`，**具体弃用版本未确认**（疑 macOS 15.0，未验证） | A4 官方 |

直接后果：**ADR-003（最低 macOS 14）与 ADR-007（采集主路径 = SCScreenshotManager）互为前提**。若 Q-01 选 macOS 13，主路径退回 `CGDisplayCreateImage`（已弃用、无未来），代价必须写在 ADR-007 里。

## 8. 差距总账

| 类别 | 条目 |
|---|---|
| 我们有意不做（首版） | 历史回放、自由选区、GIF/APNG、贴图分组、水印/边框/圆角效果、OCR、缩略图模式、自动保存 |
| 我们比 Snipaste 多做 | 贴图内二次编辑（PRO 能力）进 P0；序号徽章（PRO）进 P0；圆角/虚线/箭头端点（PRO）进 P0 样式 |
| Snipaste 有、我们目前**漏列** | **橡皮擦**（免费档就有）→ 建议进 Q-03；"关闭贴图可恢复 / `⇧Esc` 销毁"的二态语义 → 我们 P0 只有一种关闭 |
| 待用户裁决新增 | ① 是否把橡皮擦加进 P0 工具集；② 贴图透明度键位是否照 `⌘`+滚轮（已据此改 FR-PIN-004 关联键位）；③ 已知 D-04 = Snipaste PRO 能力，是否仍坚持 |

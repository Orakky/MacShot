# 逐屏原型与规格

> 真源：**屏幕与元素规格**（`UI-00n`）。数值一律引用 `docs/design/design-system.md` 的 token；状态机见 `docs/design/state-machines.md`；键位见 `docs/design/keymap.md`。
> 线框是"位置与层级"的约定，不是像素稿；实现时以元素规格表为准。
> P0 屏 = UI-001…UI-007；UI-008/UI-009 属 P1 但契约先定（避免后面返工）。
> **可操作对照**：`prototypes/index.html`（T-060，证据 E-014）—— 9 屏共用一套标注文档，可拖选区/画标注/⌘P 贴出/缩放/取色。规格仍以本文为准；原型只回答"手感对不对"，**不证明** TCC、window level、键盘焦点（那是 T-101/T-102/V-021）。

### 交互（详见 `overlay-and-selection.md` §4）

- 按下于暗化区 → 新建选区（旧选区清除）；`⇧` 从中心展开；`⌥` 锁正方形（**待核实 Snipaste 的约束键**，`docs/reference/snipaste-gap.md` §1 未记约束键）。
- 拖把手/移动用 `MSSelectionGeometry`；小于 `4pt` 的释放视为点选（P0 取消会话，P1 走窗口识别）。
- 键盘：方向键微调（P1 `FR-CAP-013`）、`Enter`/双击提交、`Esc` 取消、`⌘C/⌘P/⌘S/⌘⇧S` 各自提交意图。
- 焦点：不激活 app（FR-SESS-003）；`text` 工具例外（`overlay-and-selection.md` §2）。
- **退出路径必须不止一条**（遮罩是全屏模态，收不到键就等于糊住整台机器）：
  ① `Esc`；② **再按一次截图键**（`F1` 切换开/关）；③ app 失去活跃状态（系统弹窗、别的 app 抢前台）自动收窗；
  ④ 采集/提交出错也强制收窗（`cancelSession()` 幂等，状态机拒绝迁移时仍强制关窗）。

### 边界态

| 情况 | 表现 |
|---|---|
| 无权限 | 不进入本屏，走 `UI-007` |
| 选区贴边 | 读数翻内侧；把手仍完整可命中（不被窗边缘吃掉） |
| 选区 = 整屏 | 警告：整屏贴图很大（仅提示一次/会话） |
| 多显示器 | 遮罩只在光标所在屏；`⌥→`/菜单切换显示器属 P1 |
| 拔掉显示器 | 用布局快照完成，不重开遮罩（FR-SESS-004） |

## UI-002 标注工具条 + 样式条

目的：选工具、调样式，全部在一横条内完成，不弹二级窗。
出现：有选区后（`dur.fast` 淡入）；默认吸附在**选区下沿外侧 8pt**，越界翻到上沿，再越界则压在选区内下沿（半透明）。

```
┌───────────────────────────────────────────────────────────────────────┐
│ ▭  ◯  ↗  ⤳  ✏  🖍  T  ①  ▦  ⌫ │ 红 橙 黄 绿 蓝 紫 黑 白 ✚ │ 3pt ▁ │ ⇢ ▾ │ ⌫ │ ↶ ↷ │ ⌘C ⌘P ⌘S  ✕ │
└───────────────────────────────────────────────────────────────────────┘
   └── 工具（9 件，Q-03）──┘  └── 色板（8+自定）──┘  └线宽┘ └端点┘ └虚线┘ └撤销┘ └提交┘
```

### 元素规格

| 组 | 内容 | 规格 |
|---|---|---|
| 工具 | 矩形、椭圆、箭头、折线、画笔、荧光笔、文字、序号、马赛克/模糊、橡皮擦（橡皮擦是否进 P0 = Q-03） | 按钮 `ctrl.h`=28pt，图标 16pt，间距 `sp.1`；当前工具底色 `accent` @ 16% + 图标 `accent` | **（11-17 已裁 Q-03＝9 件全进 P0）** **11-17 起格子里画的是 SF Symbol（`design-system.md` §5 / `V-050`），字母只作回落与键位提示**
| 色板 | `design-system.md` §2.2 的 8 格 + 第 9 格"自定/取色" | 18pt 圆形，选中加 2pt `float.surface` 内环（保证任何底色可辨）；点击即改 `currentStyle.strokeColor` |
| 线宽 | 无级滑条 1–12pt（P0）+ `1`–`5` 档位（P1，Snipaste 档位属 PRO） | 宽 72pt；改动只影响后续元素（FR-ANN-003 判据） |
| 端点/形状变体 | 单箭头/双箭头/三角、实线/虚线/点线、圆角 0/4/8 | 弹出样式条（`dur.fast`），选项 ≤ 12 个，全部单行 |
| 模糊参数 | 类型（马赛克/高斯）+ 半径 4–40 | 仅当当前工具是模糊时出现（不常驻，防噪音） |
| 撤销/重做 | 图标置灰条件 = 栈空 | FR-ANN-005 |
| 提交 | 顺序＝**贴出 `Enter`** · 复制 `⌘C` · 保存 `⌘S` · 取消 `✕`；`⌥Enter`＝复制（默认档＝贴出时）。**四个动作都可点击，点＝按同一个键**（11-18 修：此前只是画上去的字，命中区整条一律被工具条吃掉）；格子由 `MSAnnotationToolbar.actionBoxes(rect:labels:)` 给出，绘制与命中同一份几何，窄屏 `showsActions=false` 时格子一起收。`.commit` 那格的动词跟随设置项 `commitBehavior`，用短文案（贴出／复制／保存）——长文案"保存到文件"会把四段撑过预留的 250pt 挤到色板上 | **主操作是"贴出"**：`accent` 实底 + 白字，其余出口是描边按钮；四个动作都带键位提示（鼠标用户也要能学键盘）。理由与判据见 `FR-PIN-018`：截图后最常见的动作是"钉住看"，所以一等出口必须是它 |

规则：
- 工具条**不遮挡选区内容**优先于"贴边吸附"，宁可压进选区 12pt 也不超出屏幕。
- 任何时刻只有一条工具条；样式条是它的展开态，不是第二个浮层。
- 按钮命中区 ≥ `hit.min`（24pt），图标可以小于命中区。
- 鼠标移出选区 300ms → 工具条降到 70% 不透明（不消失，与 Snipaste 的"移出即隐藏"刻意不同）= 待裁决 **Q-14**（登记在 `docs/charter.md` §6）。

## UI-003 贴图（浏览态）

目的：把图钉在内容之上，可移动/缩放/透明/复制/保存/再编辑。
出现：`⌘P` 提交、`F3` 剪贴板贴图（FR-PIN-006）。

```
              ┌──────────────────────────────┐
              │                              │   ← 无标题栏；hasShadow + 边缘光晕（见 UI-003b）
              │        位图 + 标注层          │
              │                              │
              │                    ┌───────┐ │
              │                    │200%   │ │   ← 角标：倍率 / 透明度 / 未导出
              │  ● 双击=关闭       └───────┘ │
              └──────────────────────────────┘
   悬停（鼠标进入）→ 顶部淡入一条迷你操作条（16pt 高，纯图标）：
   ┌──────────────────────────────┐
   │ ⧉ 复制   ⤓ 保存   ✎ 编辑   ⊘ 穿透(P1)  ✕ │
   └──────────────────────────────┘
```

| 元素 | 规格 | 出处 |
|---|---|---|
| 窗口 | `NSPanel` nonactivating、level=ADR-019、跨 Space | FR-PIN-001/004 |
| 初始尺寸 | = 选区逻辑尺寸（`canvasSize / scale`），首次出现按提交时的屏幕位置对齐（原位贴出 = P1 `FR-PIN-014`） | FR-PIN-001 |
| 角标 | 倍率、透明度、"未导出"三态合一枚药丸，`font.ui.small`，`pin.badge.surface`，右下角外缩 6pt；100%+不透明+已导出时**完全隐藏** | `annotate-model.md`、`export-clipboard.md` |
| 悬停操作条 | `dur.fast` 淡入，移出 400ms 淡出；`⇧` 按住时强制显示 | 原则 1 |
| 缩放 | 滚轮 ×1.1/格，指针为锚；`⌘0` = 100% | FR-PIN-003 |
| 透明 | `⌘`+滚轮 ±5%；`⌘1`…`⌘9` | FR-PIN-017 |
| 关闭 | `⌘W` / `Esc` / 双击 / 操作条 ✕（P0 = 直接销毁，Q-13） | FR-PIN-002 |
| 右键菜单 | 复制 / 保存 / 贴到 100% / 透明度档位 / 显示标注(P1) / 穿透(P1) / 关闭。**标题里不写组合键**（用户 11-19：菜单只当鼠标出口）——按键仍由 `MSPinView.keyDown` 实现，`keyEquivalent` 一直是空串，所以摘掉装饰文字不摘掉功能 | `pin-window.md` §5、`V-061` |

"未导出"标记：编辑过标注但没复制/保存就关闭 → 丢失（Q-06 的代价）；因此角标常驻直到任一导出发生，关闭时若无导出给一次性确认（**只在关第 1 次时问，之后记住偏好**）。

## UI-003b 贴图边缘光晕（P0，11-18 用户要"悬浮感"）

```
      ┆ ┆ ┆ ┆ ┆ ┆ ┆ ┆ ┆        ← 留白 10pt：三层白色软环（2/5/9pt @ 30/15/7%）
    ┌───────────────────┐      ← 紧贴外沿一圈 1pt 高光 @45%，界才干净
    │      截图内容      │      ← 内容区域一个像素都不许被覆盖（奇偶裁剪保证）
    └───────────────────┘      ← 系统窗影（hasShadow）负责浅色桌面上的接地感
```

- **为什么不是边框**：`design-system.md` §8 明令"给贴图加彩色边框当默认"不做。光晕是**中性白色、由内向外衰减**的软边，
  不是等宽实线框；深色桌面上看得见，浅色桌面上主要由窗影承担——两种情况下都不改变内容。
- **几何**：窗尺寸 = 图片 + 每边 `MSPinGlow.pad`；`imageRect` 仍是唯一来源（位图、矢量层、工具带、徽章、
  `docPoint` 全从这里取），工具带长在**留白之上**，不许压在光晕上。
- **绘制顺序是判据的一部分**：光晕最后画 + 奇偶裁剪到留白。少任何一个，"看到的效果"就会开始吃
  "复制出去的图"（`NFR-011`）。上一版把光晕画在位图**之前**，判据因此是空的——反证跑下去照样绿。
- 不可配置（开关属 `FR-PIN-013` 的 P1 剩余部分）。

## UI-004 贴图内再编辑态

目的：不重新截图就能改标注（D-04 的可见承诺）。
进入：`E` 或操作条 ✎。退出：`Enter`/`Esc`。

> 实现状态（2026-11-17，`B-028` 定稿＝**撑高贴图窗**，判据 `E-061`）：
> ① **编辑态里再按 `E` 是选橡皮擦**，不是退出（`E` 在 §3 归橡皮擦；退出用 `Enter`/`Esc`，
> 上下文优先级写进 `keymap.md` §4）；② 工具条自然宽 404pt，贴图窄于它时**不再折行、也不再盖画面**，
> 而是把窗口在图片**下方**撑高一条工具带：`strip = min(160pt, 图片高)` 预算内按实际摆放需要的高度取值
> （`300×200` 实测 `strip=78pt`＝两行：上行工具、下行色板）；③ 预算都不够（如 `60×40`）⇒ **不撑带**，
> 只画"✎ 编辑中 · 按字母选工具"提示条，这是写进的边界而非缺陷；④ 撑带时窗口**顶边不动、向下长**，
> 图片区域与导出像素与非编辑态逐字节相同。

```
        ┌──────────────────────────────────┐
        │  ✎ 编辑中        （选区外仍可拖窗：⇧+拖） │
        │ ┌────────────────────────────┐   │
        │ │  位图 + 标注 + 把手/网格     │   │  ← 图片区域 = imageRect，尺寸与导出都不变
        │ └────────────────────────────┘   │
        ├──────────────────────────────────┤
        │ [▢][○][↗][⌇][✎][⌑][▦][#][◇][⌫]  │  ← 工具带 strip：UI-002 同款格子（图标，非字母），长在图片下方
        │ ●●●●●●                           │     窄贴图时排两行；遮罩侧仍是单行规格
        └──────────────────────────────────┘
```

- 工具条与 UI-002 **同一实现**，只是宿主不同（`annotate-model.md` §9）。贴图尺寸可能小于工具条 → 工具条允许横向滚动 + 次要组折入 `⋯`（不许缩小到命中区 < 24pt）。
- 编辑态下 `isMovableByWindowBackground = false`，移动贴图用 `⇧`+拖 或边框拖（`pin-window.md` §4）。
- 画布尺寸不可改（P0）；需要更大画布 → 回遮罩重截。
- 退出编辑 = 提交到同一张贴图，窗口 id 不变（FR-PIN-005 判据）。
- 编辑态的撤销栈属于这张贴图，退出编辑不清空。

## UI-005 设置窗

目的：少数几个真会改的值，一屏放完，不做多标签。

> **窗高不许手写常量**：控件栈钉满上/左/**右/底**四条边，窗口高度按 `stack.fittingSize.height + 32` 算。
> 这条是 11-19 补的规矩——历史上 300 → 460 两次手改窗高，第三次（加了「启动」分组与权限行，栈自然高 573）
> 没人再改，于是「开机时自动启动 MacShot」被画到窗外 `@y=-105..-87`，用户在设置里根本找不到这个开关。
> 判据 `V-062`：`make probe-settings` 打印每个控件在窗坐标里的 y 范围，裁切=有 就直接 rc=7。

```
┌──────────────────────── 设置（⌘,）────────────────────────┐
│ 常规                                                        │
│   开机时自动启动 MacShot [ ]   ← 启动分组，读写 SMAppService  │
```

## UI-007 权限引导窗（FR-CAP-006）

**只有一种情况允许开这扇窗**：采集失败且系统当场回答权限是 `denied`。别的失败（display 找不到、后端报错、空画面）只出 toast；
而"系统说已授予却报缺权限"这种自相矛盾必须改说空画面——11-20 用户就是被这条谎报卡住过（判据 `V-068`）。

```
┌──────── 需要「屏幕录制」权限 ────────┐
│ ⛭ 截图需要系统允许 MacShot 读取屏幕内容。│
│                                     │
│ 1. 打开 系统设置 → 隐私与安全性 → 屏幕录制与系统录制  │
│ 2. 勾选 MacShot                     │

│                                     │
│ ⓘ 目前截图会得到全黑画面，这不是 bug。 │
│      [ 打开系统设置 ]  [ 重启 MacShot ]  [ 稍后 ] │
└─────────────────────────────────────┘
```
- 模态仅在**首启未授权**时；会话中检测失败只给一次性提示（`UI-009`），不打断。
- "打开系统设置"必须真的定位到该面板（`docs/runbook/permissions-tcc.md` 给 URL scheme）。
- macOS 各版本面板名称不同（"屏幕录制" / "屏幕与系统音频录制"），文案按系统版本选择——**待实测**（`T-004`）。

## UI-008 放大镜（P0，11-17 已落地）

```
        ┌────────────────┐
        │ ▪▪▪▪▪▪▪▪▪▪▪   │  17×17 像素，近邻放大到 170pt（网格 10pt/格）
        │ ▪▪▪▉▪▪▪▪▪▪▪   │  中心像素描 accent 框
        │ ▪▪▪▪▪▪▪▪▪▪▪   │
        ├────────────────┤
        │ ▪ #595959  X:1020 Y:560 │  ← font.readout；C 复制色值，⇧C 切 Hex/RGB
        └────────────────┘
```

- **位置**：默认指针**右下 20pt**。被选区把手压住就**换象限**（左下 → 右上 → 左上），
  而不是把框顶开一大段——放大镜必须贴着指针，飘走了就看不见取的是哪个像素（11-17 第一版就是这么错的）。
  四个象限都放不下才夹回屏内，宁可重叠也不出屏。
- **出现**：`⌥` 按住＝强制呼出（**这是默认档唯一入口**）；设置项「拖拽时显示放大镜」=开 时才在拖新选区时自动出现；都不满足就收起。
  "拖拽档"只认**选区**拖拽（新框/移动/改尺寸）——画箭头、画矩形时不许弹，设置开着也不弹。
  锚点必须跟鼠标：拖拽期间系统不再发 `mouseMoved`，只在 `mouseMoved` 里更新锚点会让放大镜停在
  "最后一次悬停的位置"，放大的是别处的像素（11-18 用户第二张截图就是这个样子）。
  **11-18 改判**：原规格把"拖拽时自动"当默认，用户明确不要截图时那个额外画面 ⇒ 默认档翻成不自动弹（`charter.md` §6b 的 Q-07 呈现档行）。字段名保留、默认值变，偏好 schema 3 → 4。
- **读数**：色值 + 像素坐标。`C` 复制的是**色值本身**（坐标复制过去没意义），`⇧C` 只在 Hex/RGB 两档间循环——
  规格没有第三档，实现不自作主张加。
- **`W/A/S/D` 逐像素**：本期不做（`FR-CAP-016` 明确移出 P0）。
- **色差事实**：放大镜格子的显示色与取样色之间有 ~4% 的偏移，那是**色彩管理往返**（sRGB→显示器→deviceRGB），
  不是取错像素。判据因此分两层：数据层要求放大图中心像素**精确等于**取样色，渲染层只允许小偏移、
  但必须明显更接近取样色而不是隔壁像素（`E-068`）。

## UI-010 检查更新结果（P0，11-19 落地）

用途：**只有用户点「检查更新…」才会出现**。没有自动检查、没有启动提示、没有后台轮询（`ADR-023`）。

```
有新版：
  发现新版本 MacShot 0.2.0（当前 0.1.0）
  <源里写的更新说明>
  文件：MacShot-0.2.0.dmg　大小：1.6 MB
  SHA-256：3ebeb4a4ef54118f…
  下载位置：~/Downloads
  校验和一致才会挂载；不一致会直接删掉并报错。
        [ 下载更新包 ]   [ 复制下载链接 ]   [ 稍后 ]

已是最新 / 失败 / 清单坏：单条信息 + [好]，不催第二次。
```

- **面板先交代证据再让人决定**：大小、校验和前缀、落地目录都写出来——"让用户自行选择是否需要更新"
  的前提是他看得见自己在同意什么。
- 下载完成才挂载（`NSWorkspace.open`），随后一句指引"把 MacShot 拖进应用程序替换后重开"。
  **不做自动替换/自动重启**：那会绕过用户，而且自签包在别的机器上 Gatekeeper 不认（`ADR-023` 的诚实边界）。
- 校验和不符 ⇒ 删文件、报错、不挂载。这条分支必须有判据（`V-065②`），否则"校验"只是文案。
- 源地址可被 `MACSHOT_UPDATE_URL` 覆盖（内测与自建源用），面板不显示这个变量的存在与否。

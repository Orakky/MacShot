# 键位总表（真源）

> 真源：所有键位与冲突提示文案。代码里的键位常量表、`screens.md` 的键位提示、README 的快捷键说明都从本文取。
> 全局热键的**默认值**受 Q-02 裁决；带 `⚠` 的行有已知冲突或权限风险。

## 1. 全局（app 不在前台也有效）

| 动作 | 默认 | Snipaste 对应 | 出处 | 状态 |
|---|---|---|---|---|
| 截图 | `F1` | `F1` | 官方 S1 | 待裁决 Q-02 |
| 贴出剪贴板图像 | `F3` | `F3` | 官方 S1 | 待裁决 Q-02 |
| 全屏截图（整屏直出） | `⌘A` | `⌃A`（macOS 用 `⌘` 替换 `⌃`，S2 页首） | ⚠ `⌘A`=全选，冲突概率高，实测后可能改 `⌥⌘A` | 待裁决 |
| 隐藏/显示所有贴图 | `⇧F3`（P1） | `⇧F3` | 官方 S1 | P1 |
| 截图并重复上次区域 | `⌥F1`（P1） | 截图态按 `R` | 官方 S2 | P1，且我们在"遮罩外"也要能用 |

`⚠` 功能键通用风险：MacBook 的 `F1/F3` 默认是亮度/调度中心，需要 `fn` 或在系统设置里打开"将 F1、F2 等键用作标准功能键"。第三方与金山镜像 FAQ 有反映，Snipaste 官方文档未提 → 设置窗与首启提示必须写明（`docs/reference/snipaste-gap.md` §1）。

## 4. 贴图

| 键 | 动作 | 状态 | ID |
|---|---|---|---|
| 滚轮 / `+` `-` | 缩放（指针为锚） | P0 | FR-PIN-003 |
| `⌘0` | 回到 100% | P0 | FR-PIN-003 |
| `⌘`+滚轮 | 透明度（对齐 Snipaste 官方键位；原稿写的 `⌥`+滚轮已订正） | P0 | FR-PIN-017 |

| `⌘C` | 复制（100% 烘焙） | P0 | FR-EXP-002 |
| `⌘S` / `⌘⇧S` | 保存 | P0 | FR-EXP-003 |
| `⌘W` / `Esc` / 双击 | 关闭（P0 = 销毁） | P0 | FR-PIN-002、Q-13 |

## 6. 键盘-only 全链路（可访问性判据）

`F1` → 方向键调选区（P1 到位后）→ `A` 画箭头 → `⌘C` 复制 → 焦点回原 app。**这条链在 P1 的 FR-CAP-013 完成前是不闭合的**（选区只能靠鼠标框），需在发布说明里写明，不许宣称"全键盘可用"。

| D-01 | 首版范围 | **只做四大件最小闭环**：快速截图、图片置顶（贴图）、图片标注、一键存到剪贴板。其余全部降级 P1/P2 | 范围纪律：**一条 P0 必须能映射到四大件之一**，映射不到自动降 P1。当前条数以 `docs/requirements/requirements.md` §0 为唯一口径（本节不复制数字） | ADR-006 |

### 1.1 D-01 与 D-04 的冲突（明示，不掩盖）

- 冲突：最小闭环要求实现面尽量小；D-04 要求贴图携带可编辑文档，等于把"文档格式 + 再编辑器"提前进 P0。
- 已定代价（接受）：
  1. `MSAnnotationDocument` 的 Codable schema 与版本号在 **M1 出口**冻结（`schemaVersion` 字段 + 迁移器）。
  2. 贴图窗必须能唤起标注编辑态（同一套渲染器，两套宿主），渲染器接口在 M1 出口定型。
- 对策（用来把代价压住）：
  1. P0 **不做**独立"快速编辑器"窗口 —— 再编辑就在贴图窗内进行，少一个窗口形态。
  2. P0 **不做**文档版本迁移 UI，只保留 `schemaVersion` 与"读旧版失败即拒绝并提示"的兜底路径。
  3. 导出（剪贴板/文件）走"文档→位图"单向烘焙，导出物不携带文档，避免双向同步。
- 判据：若 M1 出口发现再编辑导致贴图窗内存或帧率不达标（见 NFR-005），则回到 §6 重新裁决 D-04，不得由 agent 自行降级。

## 2. 产品定义

| 项 | 内容 |
|---|---|
| 名称 | MacShot |
| 一句话 | macOS 原生截图 → 标注 → 贴图置顶 → 剪贴板的一体化工具，形态对齐 Snipaste |
| Bundle ID | `com.macshot.app` |
| 运行形态 | 菜单栏常驻（`LSUIElement`，无 Dock 图标）+ 全局热键唤起 |
| 目标用户 | 开发者 / 设计 / 需要频繁截图对照与标注的人；首版=自用 |
| 明确不是 | 不是截图管理/相册；不是标注设计工具；不做云端同步 |

## 3. 术语表（中文 ↔ 代码标识符，强制统一）

| 中文 | 代码/文档标识 | 定义 |
|---|---|---|
| 截取会话 | `CaptureSession` | 一次"冻结屏幕→选区→标注→提交"的完整生命周期 |
| 遮罩 | `Overlay` | 全屏半透明选区窗口，覆盖在所有内容之上 |
| 选区 | `Selection` | 遮罩内的矩形区域，逻辑坐标（AppKit，y 向上） |
| 像素区 | `PixelRegion` | 设备像素矩形（原点在所属显示器左上，y 向下） |
| 冻结帧 | `FreezeFrame` | 会话开始时抓下的全屏位图，选区从中裁剪 |
| 贴图 | `Pin` | 置顶悬浮的图片窗口 |
| 标注文档 | `AnnotationDocument` | 位图画布 + 有序矢量标注元素 + schema 版本 |
| 标注元素 | `AnnotationElement` | 单个标注（矩形/箭头/文字/马赛克/…） |
| 提交 | `Commit` | 会话结束动作（复制/保存/贴出/取消） |
| 放大镜 | `Loupe` | 像素级取色与像素网格视图 |
| 判据 | — | 一条可被人或脚本观察证实的事实；未观察到不得写"已完成" |

**坐标规约（全项目唯一）**：逻辑=AppKit 全局（主屏左下原点，y 向上）；像素=显示器本地（左上原点，y 向下）。任何跨空间换算必须写成显式函数，禁止"顺手减一下"。

## 4. 模块命名与依赖（唯一清单，见 `docs/architecture/modules.md` 取职责）

`MSCore` ← `MSSettings` ← `MSHotKey`
`MSCapture`（依赖 Core/Settings）→ `MSOverlay` → `MSSession`
`MSAnnotate`（依赖 Core）→ `MSPin`（依赖 Core/Settings/Annotate）
`MSExport`（依赖 Core/Annotate）
`App/` = 组合根，唯一可做全局装配的地方。

- 禁止：模块间循环依赖；`MSCapture` 依赖任何 UI 模块；`MSAnnotate` 依赖 `NSWindow`。
- 新增/改名模块 = 一条 accepted ADR + 改本节 + 改 modules.md。

## 7. 非谈判项（工程纪律）

1. **未观察不写完成**：任何"已完成"必须附判据（命令输出 / 截图 / 日志行 / 读数）。
2. **未 accepted 的 ADR 不落地为代码**：状态 `proposed` 的决策不得出现在实现里。
3. agent 不改 `project.pbxproj`；需要新增资源/源码 → 放进同步文件夹组，让 Xcode 自动纳管。
4. 不在 `App/` 之外写全局单例；依赖注入走组合根。
5. `git push` 由用户在终端执行；agent 只做本地提交，且只 `git add <显式路径>`。
6. 改文档 = 同批改其索引条目与 ID 引用；禁止只加不更。
